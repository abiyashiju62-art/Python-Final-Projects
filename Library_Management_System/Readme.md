# Library Management System
A simple Library Management System developed using Python and SQLite. This project helps manage books, users and borrowing through a menu interface.

## Features
1. User registration and login
2. Admin and user roles
3. Add, View, Search, Update and Delete books
4. Borrow and return books
5. Automatic book quantity updates
6. Input validation and error handling
7. SQLite database for storing records

## Technologies used
- Python
- SQLite
- sqlite3module
- Visual Studio Code

## How to run the code
1. Make sure Python is installed on your system
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:
     Python main.py

  ### Default Admin Login 
   The system includes a default administrator account.
   - **Username:** admin
   - **Password:** admin123
  ### User Login
   - New users must register through the registration option.
   - Registered users can log in using their username and password.
   - Users can view books, search books, borrow books and return borrowed books.
